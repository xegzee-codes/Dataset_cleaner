# Dataset Cleaner
A simple Python utility to remove duplicate lines from a text dataset, making it ready for AI model training or evaluation.

## Features
- Removes duplicate lines
- Preserves original order
- Handles errors gracefully

## How to use
1. Place your raw text file in the same folder.
2. Run `python dataset_cleaner.py`
